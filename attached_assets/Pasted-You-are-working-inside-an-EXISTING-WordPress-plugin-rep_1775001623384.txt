# 🧩 PART 1: MAINTENANCE CHECKLIST (WP ADMIN)

## Permissions

* Only users with role: `company_super_admin` can access
* Hide menu and functionality from all other users

---

## Admin UI

* Add a top-level menu item: **Maintenance**
* Build a checklist table UI using native WordPress styles

---

## Tasks System

Define default tasks in code:

* Update plugins (monthly)
* Remove unused plugins (monthly)
* Verify reCAPTCHA is active (monthly)
* Verify forms have valid email addresses (monthly)
* Verify forms have reply-to configured (monthly)
* Verify Formidable spam filters (monthly)
* Verify LUMN Security Plugin installed & updated (monthly)
* Run WordFence scan (monthly)
* Update admin email to [dev@getlumn.com](mailto:dev@getlumn.com) (one-time)
* Update copyright (yearly)
* Check console log for errors (monthly)

---

## Data Model

Each task must include:

* id (slug)
* label
* interval (seconds; 0 = one-time)
* last_checked (timestamp)
* completed (boolean)

Store using:
`update_option('lumn_maintenance_tasks', $tasks)`

---

## Behavior

* Display:

  * Checkbox
  * Last checked date
  * Next due date
* When checked:

  * Save via AJAX (no reload)
  * Update last_checked timestamp

---

## Reset Logic

* If `time() > last_checked + interval`, mark incomplete
* One-time tasks never reset

---

## UI Enhancements

* Color-coded rows:

  * Red = overdue
  * Yellow = due within 7 days
  * Green = completed

# 🌐 PART 2: GOOGLE SHEETS INTEGRATION

## Goal

Send maintenance summary data from each WordPress site to a Google Sheet using a webhook (Google Apps Script).

---

## Data to Send

On sync, send:

* site_url
* total_tasks
* incomplete_tasks
* oldest_unchecked_task_timestamp
* last_checked_timestamp (current time)
* api_key (for authentication)

---

## Implementation

Create a function:

* `lumn_send_maintenance_to_sheet()`

This function should:

1. Load all tasks
2. Calculate:

   * total tasks
   * number of incomplete tasks
   * oldest unchecked task timestamp
3. Send a POST request using `wp_remote_post()` to a configurable webhook URL

---

## Config Settings

Add plugin settings for:

* Google Script Webhook URL
* API Key (shared secret)

Store in WordPress options.

---

## Security

* Include API key in payload
* Do not send data if webhook URL is empty

---

## Triggering Sync

Trigger sync:

* On checklist update (after save)
* AND via daily WP-Cron job

Register cron event:

* `lumn_daily_sync`
